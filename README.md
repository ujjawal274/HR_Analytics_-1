# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

The **HR Analytics Dashboard** is an interactive Business Intelligence solution developed using **Microsoft Power BI** to analyze workforce data and provide actionable insights for HR decision-making. The dashboard enables stakeholders to monitor employee demographics, workforce trends, attrition, and key HR metrics through dynamic and interactive visualizations.

The primary objective of this project is to transform raw HR data into meaningful insights that help organizations improve employee retention, optimize workforce planning, and support strategic HR initiatives.

---

## 🎯 Objectives

* Analyze employee demographics and workforce composition.
* Monitor employee attrition and retention trends.
* Identify departments with high turnover.
* Track workforce KPIs through interactive dashboards.
* Enable data-driven HR decision-making.
